hash-pinned-identity C0 deterministic

A launcher refuses to run any executable whose resolved absolute path and SHA-256 don't both match a policy pinned outside the workspace — even if the name on PATH is identical.

The whole idea in its simplest form: name exactly what may run, refuse everything else. A byte-identical impostor in another directory is still refused.

exact-plan-approval-gate C0 deterministic

A destructive action can only be approved by echoing back the exact SHA-256 of the plan that was shown — a "yes" with no hash is rejected.

Consent has to name what it consents to. A “yes” with no hash is not an approval, and an approval does not survive an edit to the plan.

authenticated-transition-ledger C0 deterministic

An append-only, SHA-256-chained, HMAC-signed event log detects a single edited byte anywhere in its history, not just at the tampered row.

Evidence that cannot be quietly corrected. One edited byte anywhere in history is detected — and a careful attacker who recomputes the hash still cannot forge the signature.

capability-gated-tool-invocation C0 deterministic

A tool call runs only if the calling persona's declared capability set contains that tool's exact required capability — and a denied call never enters the tool function at all.

Authorization at the call site, not in the audit afterwards. The denied tool’s body is never entered, and the test proves it by counting.

optional-input-does-not-block C2 deterministic

A run starts when every required input is present, even if every optional one is missing — a missing optional input is recorded and the run marked degraded, never escalated into a stop.

The counterweight, and the one most catalogs never teach. After four refusals, the discipline of not refusing: a run starts on a bare prompt, because blocking on context you never needed is its own failure.

governed-call-path composition

One request through seven gates in a fixed order. The first gate that refuses stops it: no later gate is entered, no effect occurs, and the ledger records which gate refused.

A control plane that nothing routes through is documentation. This is the smallest artifact that shows the primitives actually fitting together — and it is still not an orchestrator: no router, no scheduler, no second agent, no loop.
